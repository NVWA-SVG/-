# 花名册批量文件重命名助手

这是一个完全在本地运行的工具，用花名册将同一文件夹中的“姓名.扩展名”批量改为“姓名_学号_项目.扩展名”。工具不会上传文件或个人信息，也不需要 DeepSeek API、Docker 或额外 Python 库。界面使用 Windows 自带的 PowerShell/.NET，不依赖 Python Tkinter。

## 完整流程

```text
准备花名册
  ↓
把待处理文件放进同一文件夹
  ↓
选择文件夹和花名册
  ↓
设置项目名与命名模板
  ↓
预览（不修改任何文件）
  ↓
解决红色冲突
  ↓
确认执行
  ↓
如有需要，撤销最近一次操作
```

## 1. 准备花名册

支持 `.csv`、`.tsv`、`.xlsx`，第一行必须有表头：

| 姓名 | 学号 | 项目 |
|---|---|---|
| 张三 | 20260001 | a |
| 李四 | 20260002 | b |

- `姓名` 和 `学号` 必填。
- `项目` 可以留空，然后在界面的“统一项目名”中填写。
- 学号如果以 `0` 开头，请在 Excel 中将该列设为“文本”，或使用 CSV，避免前导零丢失。
- 花名册不能有重名；重名时程序会停止，避免学号配错。

可直接复制 `花名册_示例.csv` 再修改。

## 2. 准备待改名文件

例如在一个文件夹中放入：

```text
张三.docx
李四.pdf
王五.pptx
```

文件名可以只有姓名，也可以是学号、班级、实验名和姓名的混合形式，例如：

```text
202434610215梁书前24AI2实验二_.docx
24AI2冯业成202434610204.docx
图像实验2_24AI2_刘鸣诚.docx
```

程序会优先识别文件名中的学号，其次识别花名册姓名。如果学号和姓名指向不同学生，程序会显示“冲突”而不会自动猜测。程序只处理选定文件夹的当前层，不会修改子文件夹。

## 3. 启动和使用

1. 双击 `启动助手.bat`。
2. 选择待改名文件夹。
3. 选择花名册。
4. 填写统一项目名，或使用花名册的“项目”列。
5. 点击“1. 预览”。
6. 确认没有红色“冲突”后，点击“2. 确认执行”。

默认结果：

```text
张三.docx → 张三_20260001_农业博物馆智能问答.docx
```

如果必须使用加号，可把命名模板改为：

```text
{姓名}+{学号}+{项目}
```

## 安全规则

- 预览不会修改文件。
- 花名册重名、学号缺失、项目缺失或目标名已存在时，不执行改名。
- 未在花名册中匹配到的文件只会显示“跳过”。
- 每次执行会在目标文件夹的 `.rename_history` 中生成记录。
- “撤销最近一次”会按记录恢复原名。

## 命令行用法（可选）

```powershell
python renamer.py preview --folder "C:\\待交作业" --roster ".\\花名册.csv" --project "AI大赛"
python renamer.py rename  --folder "C:\\待交作业" --roster ".\\花名册.csv" --project "AI大赛"
python renamer.py undo    --folder "C:\\待交作业"
```
